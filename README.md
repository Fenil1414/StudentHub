## Practical Modules

The practical work for StudentHub covers the following topics:

1. Project planning, requirements, sitemap, and wireframes
2. Semantic HTML5 pages
3. Responsive CSS design
4. JavaScript DOM manipulation and events
5. Registration form validation
6. Fetch API, JSON data, search, and filtering
7. PHP form processing and server-side validation
8. MySQL database design and connectivity
9. Secure user registration
10. Login, logout, sessions, and role-based access
11. Student management using CRUD operations
12. Event management and poster uploads
13. PHP JSON API and Fetch-based CRUD
14. Admin dashboard, dynamic menu, and role-based access control
15. Final integration, testing, documentation, and deployment

## Local Setup

1. Install [XAMPP](https://www.apachefriends.org/).
2. Place the project folder inside the XAMPP `htdocs` directory.
3. Start **Apache** and **MySQL** from the XAMPP Control Panel.
4. If a practical includes an SQL file, import it using phpMyAdmin.
5. Configure the database connection in the relevant practical if required.
6. Open the relevant practical through `http://localhost/` in your browser.

## Repository Structure

Practical work is organized into individual practical folders. The repository currently includes the `Pr1` folder; additional practical folders can be added as they are completed.

The purpose of StudentHub is to apply web technology concepts in a practical project, including page design, form handling, database operations, authentication, API communication, and access control.
